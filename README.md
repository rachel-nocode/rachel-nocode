## 💻 About this repo

Source for **[rachelnocode.com](https://rachelnocode.com)** — built with [Astro](https://astro.build) + a little React.

```bash
npm install      # install deps
npm run dev      # local dev → localhost:4321
npm run build    # production build
```

```
src/
  pages/         routes — home, /taptallypro, /maxxtoken
  layouts/       shared page shells
  components/    UI bits
  maxxtoken/     MaxxToken landing (React)
  styles/        global.css
```
